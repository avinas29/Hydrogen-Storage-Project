Part 4Turning a formula into numbers

Report: §3.4, Appendix A

A model cannot read "LaNi₅". It needs numbers. This part shows exactly how a formula becomes 38 numbers, with LaNi₅ computed by hand, so you can do it on the board if asked.

Understand

4.1The idea: describe an alloy by its elements

Each element has known properties (mass, size, electronegativity …). An alloy is a mixture of elements in given fractions. So we describe the alloy by statistics of its elements' properties, weighted by how much of each element there is. This is the standard "composition-based descriptor" approach (Ward et al. 2016, "Magpie"). All elemental values come from pymatgen's periodic table, none typed by hand.

The rule: composition only
Inputs come only from the chemical formula. No ΔS, pressure, temperature, capacity or H/M is ever used as an input (the build script asserts this). That is what makes the model usable for an alloy that has never been measured.

Pruning: if two descriptors were almost identical (|Pearson r| > 0.95), the less interpretable one was dropped. This removed the radius standard deviation (r = 0.999 with δ) and the maximum molar volume (r = 0.964 with the maximum radius). 40 − 2 = 38.

4.3Worked example: LaNi₅ by hand

Step 1: atomic fractions

LaNi₅ has 6 atoms per formula unit: \(x_{La} = 1/6 = 0.167\), \(x_{Ni} = 5/6 = 0.833\).

Step 2: elemental values (pymatgen)
Elementmolar volume (cm³/mol)valence electronsradius (Å)hydride former?
La22.3931.95yes
Ni6.59101.35no
Step 3: descriptors

Mean molar volume (the most important descriptor): \(0.167\times22.39 + 0.833\times6.59 = 3.74 + 5.49 = \mathbf{9.23}\) cm³/mol.

Valence-electron mean and spread: mean \(= 0.167\times3 + 0.833\times10 = 8.83\);
std \(=\sqrt{0.167(3-8.83)^2 + 0.833(10-8.83)^2} = \sqrt{5.68+1.14} = \mathbf{2.61}\).

Fraction of hydride formers: only La counts \(\Rightarrow \mathbf{0.167}\).

Configurational entropy (units of R): \(-\sum x_i\ln x_i = -(0.167\ln0.167 + 0.833\ln0.833) = 0.299+0.152 = \mathbf{0.451}\).

Size mismatch: \(\bar r = 0.167\times1.95+0.833\times1.35 = 1.450\) Å; \(\delta = \sqrt{\sum x_i(1-r_i/\bar r)^2} = \sqrt{0.167(0.345)^2+0.833(0.069)^2} = \mathbf{0.154}\).

These match the project's code exactly (vol_mean 9.2286, vec_std 2.6108, config_entropy 0.4511, size_mismatch 0.1543).

4.4Why these descriptors make physical sense

  • Mean molar volume ↔ hole size. Bigger atoms make bigger interstitial holes, and bigger holes bind hydrogen more strongly (higher ΔH). This is the classic Lundin, Lynch and Magee (1977) correlation. In your data, vol_mean has the strongest single correlation with ΔH (Spearman 0.54, positive, as expected).
  • Fraction of hydride formers ↔ A:B ratio. More "A" atoms (La, Ti, Zr, Mg) means more strongly bound hydrogen.
  • Valence-electron spread ↔ electronic structure. Electron count affects how hydrogen bonds to the metal.
  • δ, configurational entropy: lattice strain and mixing, used in multicomponent/high-entropy alloy work (Zhang et al. 2008).
A good sign of no leakage
No single descriptor correlates very strongly with ΔH (maximum |Spearman| = 0.54). If one input correlated at 0.99, it would almost certainly be leaking the target.

4.5What composition descriptors cannot see

  • Crystal structure: the same composition can form a hexagonal C14 or a cubic C15 Laves phase with different ΔH. Descriptors are identical for both.
  • Microstructure, processing, impurities: annealing, segregation, secondary phases.
  • Pseudo-elements: mischmetal and ferrovanadium have undefined compositions, so they cannot be featurised.

These limits are one reason the error cannot fall to the measurement floor.

Defend
Q4.1What is a "descriptor" or "feature"?

A number computed from the input that the model uses, here from the chemical formula. For example, the fraction-weighted mean molar volume of the elements.

Q4.2Compute one descriptor for LaNi₅.

Mean molar volume = (1/6)(22.39) + (5/6)(6.59) = 9.23 cm³/mol. (Section 4.3 has the others.)

Q4.3Why did you remove correlated features if random forests can handle them?

Random forests do tolerate correlation, but near-duplicates (r > 0.95) add nothing and split the importance between two copies, which makes interpretation harder. Ridge regression, used as a comparison, is also sensitive to collinearity.

Q4.4Why not use DFT-calculated or structural descriptors?

Structure is known only for some compositions, and DFT for 725 alloys was beyond the project's scope. Composition-only inputs keep the model applicable to any formula. Adding structure (C14/C15, lattice parameter) is listed as the most useful future improvement.

Q4.5You added a family one-hot encoding. Did it help?

No: with and without it the MAE is 5.26 kJ/mol within one standard deviation. The composition descriptors already encode the family, so the final model uses composition only.
